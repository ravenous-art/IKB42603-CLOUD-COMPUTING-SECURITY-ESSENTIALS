# Lab 1 Report: Account Security, Identity & Access Management

## Objective
This lab focuses on securing a cloud account through identity and access management practices. The exercise demonstrates how to configure account protection, enforce access control, and verify the resulting security posture.

## Lab Overview
The lab is divided into several tasks that guide the student through:
1. Environment setup and preparation.
2. Account security configuration.
3. Identity and access management controls.
4. Verification of the configured protections.
5. Cleanup and teardown.

## Step-by-Step Report

### 1. Environment Setup
- Launch the lab environment and confirm that the virtual machine or cloud console is accessible.
- Ensure that the required account, credentials, and tools are available before proceeding.
- Confirm that the lab environment is ready for configuration.

### 2. Account Security Configuration
- Review the account security baseline and identify the relevant security settings that must be enabled.
- Configure the account with protective measures appropriate for the lab scenario.
- Apply security settings that reduce the risk of unauthorized access.

### 3. Identity and Access Management (IAM)
- Create or review IAM roles, users, or policies according to the lab requirements.
- Assign access based on least privilege and role separation.
- Ensure that administrative privileges are limited to authorized users only.

### 4. Verification
- Validate that the configured security controls are active.
- Run the verification command or checks specified in the lab instructions.
- Confirm that the environment reflects the intended secure configuration.

### 5. Cleanup and Teardown
- Remove or reset temporary configurations if required by the lab.
- Ensure the environment is returned to a safe and clean state.
- Document the final status for evidence.

## Conclusion
The lab demonstrates the importance of protecting cloud accounts and managing identities through secure IAM practices. Proper configuration, verification, and cleanup are essential to maintaining a strong security baseline.
